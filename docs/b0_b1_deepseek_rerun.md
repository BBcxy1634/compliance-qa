# B0 与 B1 DeepSeek 正式重跑

运行日期：2026-10-31  
状态：已固化  
目的：在进入 B2/B3 前，将 B0-B3 的答案生成统一为 DeepSeek

## 为什么重跑

此前 B0/B1 使用抽取式回答，DeepSeek 只负责辅助判题。抽取式结果适合诊断检索链路，但不代表项目最终的生成能力，也会使后续 B2/B3 与 B0/B1 无法公平比较。

本次 B0/B1 使用同一个生产 Prompt：

- 只使用检索上下文。
- 先直接回答结论。
- 完整覆盖条件、期限、阈值、材料、例外和步骤。
- 多来源问题需要综合，而不是逐个复述片段。
- 每个事实句或列表项标注引用。
- 证据不足时明确拒答，不补造信息。

## 结果解释

DeepSeek 生成显著解决了抽取式回答的主要缺陷：

- B0 答案正确率由 0.34 提升到 0.82。
- B1 答案正确率由 0.30 提升到 0.90。
- B1 多跳题从 0 提升到 0.80。
- B1 引用覆盖率从 0.92 提升到 1.00。
- B1 误拒答从 4 条降到 0。

检索指标保持不变，因为 BGE-M3 检索链路没有变化。正确率提升来自答案生成方式和拒答行为的改进，而不是检索召回变化。

B1 比 B0 的答案正确率高 0.08，事实题高 0.075，多跳题高 0.10。由于 B1 的检索指标与 B0 相同，这部分提升可以归因于语义切分为 DeepSeek 提供了更完整、边界更自然的上下文。

P95 延迟仍高于 3 秒目标。B0 为 3446.15 ms，B1 为 3192.82 ms。当前延迟包含 DeepSeek 网络请求和 API 响应时间，D11 需要通过模型调用优化、并发策略、上下文长度和缓存进一步压测与优化。
